# orca-companion

An e2e-loop demonstration project for the orca-companion agent harness.

## Status

This repository is an end-to-end demonstration of the orca-companion agent harness. It is not a production-ready release: the goal of the project is to exercise the planning, implementation, validation, and finalization loop in a self-contained repo, not to ship a finished product.

## Quick Links

- [NOTES.md](NOTES.md) — day-to-day observations, handoff context, and open items for the project.
- [openspec/](openspec/) — OpenSpec change proposals, specs, and configuration for each work package.
- [orca-companion.json](orca-companion.json) — harness configuration describing the coordinator model, tracker, and execution limits.
