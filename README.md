# orca-companion

> **Status: active development.** This is a demonstration project for the
> orca-companion agent harness, not a shipped library or service — nothing here
> is built, published, or run as a release.
>
> Work is planned and tracked as OpenSpec changes under `openspec/`, one
> directory per change under `openspec/changes/`. `NOTES.md` records the
> repository layout and the shell checks a reviewer runs to verify the tree.
