# Proposal: Add basic project notes

## Why

The repository has no durable, human-readable notes file. A concise root-level `NOTES.md` gives contributors one obvious place to record project context, working notes, and decisions.

## What Changes

- Add a Markdown notes document with a brief project context section and dedicated sections for dated working notes and decisions.
- Keep the document easy to extend and avoid recording unsupported implementation details.

## Impact

- `NOTES.md`
