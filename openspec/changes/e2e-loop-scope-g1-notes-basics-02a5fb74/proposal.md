# Proposal

## Why

The repository currently documents itself only through `README.md`, which describes
the project as an e2e-loop demonstration and explicitly defers all further sections
(Installation, Usage, and others) to later changes. Contributors have no place to
record scratch observations, and no agreed structure exists for capturing them. This
change introduces a minimal `NOTES.md` at the repository root so that later changes
have a predictable place to append notes.

## What Changes

- Add `NOTES.md` at the repository root containing a short purpose statement and a
  starter notes section.
- No existing behaviour, script, or configuration is modified.

## Capabilities

### New Capabilities
- `notes-basics`: The repository root carries a `NOTES.md` file that records
  freeform developer notes with a documented purpose and section layout.

### Modified Capabilities
<!-- None. -->

## Impact

- `NOTES.md` (new): the only file added or changed by this change.
