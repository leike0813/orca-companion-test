# Proposal

## Why

The orca-companion project is an e2e-loop demonstration project for the orca-companion agent harness, but currently has no dedicated notes file at the repository root. Without a `NOTES.md`, contributors have no single location to record introductory project notes, the current scope of the `e2e-loop-scope` graph generation, or the structure that future notes changes will extend, making it harder to share context across the work packages in this scope.

## What Changes

- Add a new tracked `NOTES.md` file at the repository root that captures introductory notes for the orca-companion e2e-loop demonstration project.
- The notes file documents the project purpose, the current status of the `e2e-loop-scope` graph generation (`g1`), and the headings that future notes changes (Installation, Usage, etc.) will populate.
- No other files in the repository are added, modified, renamed, or removed by this change.

## Capabilities

### New Capabilities
- `notes-basics`: A baseline `NOTES.md` file at the repository root that records introductory notes for the orca-companion e2e-loop demonstration project and establishes the heading structure that future notes changes will extend.
