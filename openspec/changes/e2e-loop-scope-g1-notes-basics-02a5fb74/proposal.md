# Proposal

## Why

The orca-companion repository is set up as an end-to-end demonstration project for the
orca-companion agent harness. It currently ships only a placeholder README and the harness
configuration file (`orca-companion.json`). Contributors landing in this repository have no
authoritative place to read project context, contributor conventions, or notes about the
e2e-loop itself. This change introduces that foundational `NOTES.md` so subsequent Work
Packages and follow-on changes can build on a stable, agreed-upon notes surface.

## What Changes

- Add `NOTES.md` at the repository root with three sections: project context, contributor
  conventions, and a short e2e-loop note.
- `NOTES.md` is created from scratch; nothing else in the repository is modified.

## Capabilities

### New Capabilities

- `notes-basics`: Establishes the foundational `NOTES.md` document that captures project
  context, contributor conventions, and a brief e2e-loop note for the orca-companion demo
  project.

### Modified Capabilities

None.

## Impact

- `NOTES.md` (new file at repository root).
