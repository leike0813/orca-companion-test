# Notes

## Purpose

`README.md` defers its detailed documentation ("_More sections
(Installation, Usage, etc.) will be added in later changes._"), so
`NOTES.md` exists at the repository root to hold the project-level
working context that has not yet earned a place on the README:
evolving conventions, in-progress decisions, status snapshots, and
pointers that would otherwise be lost when a worktree is torn down.
