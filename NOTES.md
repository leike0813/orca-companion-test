# Project Notes

These notes collect the short, practical working notes for this repository.
They stay deliberately small: each entry below points at something that is
observable in the repository today, so the list can be checked by reading the
files it names rather than by running anything.

1. `README.md` describes what the project is; this file holds the working notes
   that sit alongside it.
2. `orca-companion.json` records the harness model and execution settings for
   the project, and `openspec/config.yaml` records the OpenSpec artifact schema.
3. Changes are proposed under `openspec/changes/`, where each change carries
   its proposal, design, tasks, and spec deltas.

For the project background — what this repository is for — see `README.md`,
which stays authoritative for the project description.
