# Notes

This file is the scratchpad for the `orca-companion` project. It exists so that
observations, open questions, and short fragments of context have one predictable home
instead of being scattered across commits and chat history. Anything that belongs to the
project's contract or its public interface belongs in `README.md` or an OpenSpec spec
instead; this file is for material that does not deserve either.

Later changes append their entries beneath the `## Notes` heading below. Edits are
append-only: earlier entries stay exactly as written so the file reads as a
chronological record rather than a living document that gets rewritten.

## Notes

- 2026-09-29 — Initialized this file as part of the `notes-basics` capability. It adds
  no behaviour; it only establishes the anchor later changes append to. Example entries
  are written as `- YYYY-MM-DD — summary`, one bullet per note, so later changes can
  follow the same shape without needing further guidance.
